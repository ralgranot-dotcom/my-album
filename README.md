# 📸 האלבום שלי

אלבום תמונות דיגיטלי תלת־ממדי לאנדרואיד, בעברית מלאה, שפועל במלואו ללא אינטרנט.

**תוכנן ונוצר על ידי איתן נוה**

- האפליקציה עצמה: `app/src/main/assets/www` (HTML/JS/CSS)
- מעטפת אנדרואיד: `app/src/main/java/com/eitan/myalbum`
- כל דחיפה ל-`main` בונה APK חתום ומפרסמת אותו ב-Releases. האפליקציה בודקת את ה-Release האחרון ומציגה כפתור שדרוג.
